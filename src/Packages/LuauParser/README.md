Dex vendors the Luau port from [vantoanvh/LuauParser at feca7f0](https://github.com/vantoanvh/LuauParser/tree/feca7f036d2e24825c5b096f8979ba005e48a0cf). The package and its Luau and Lua attribution are included in the distributed module.

Dex's offline and hosted loaders both expose modules by name. EditorParserCore combines the upstream syntax types, confusable characters and parser into one module. Each call to New creates private lexer and parser state so a suspended parse can safely overlap another. The adapter observes lexeme byte ranges and accepts cooperative cancellation. Integer literals, exported values and two recovery locations are aligned with the default Luau 0.739 command-line parser.

EditorParser owns the document revision, line starts, compact token buffer and optional CST. Editor APIs use one-based UTF-8 byte offsets and exclusive ends. The active document holds one result. Four additional entries share a 256 KiB source limit. A larger secondary source can be reused through a weak reference. Derived semantic indexes owned by editor consumers have their own lifetimes. Jobs for the same source can share a suspended parser. Callers drive it in slices and independently cancel their requests. An edit reparses the document after the editor debounce. The existing structural folding path handles edits before analysis completes.

The regression suite runs tests/editor_parser.spec.luau against the editor and the packaged modules. To compare accepted syntax and diagnostic starts, run tests/editor_parser_differential.py with Luau 0.739's tests/Parser.test.cpp, --luau and --compiler. The upstream port has no test directory at the pinned revision. The official compiler supplies the expected result for each fixture under its default feature flags. tests/benchmark_editor_parser.py compares the current index with a specified Git revision using the same Luau VM.
